# Red neuronal desde cero en python

## Instalación y ejecución

```bash
python -m pip install -r requirements.txt
python neural_network_numpy.py
streamlit run dataset.py
```

## Datos y etiquetas
- Nueva York (`0`): 150 coordenadas aleatorias alrededor del centro de referencia 40.7128, -74.0060.
- Tokio (`1`): 150 coordenadas aleatorias alrededor del centro de referencia 35.6762, 139.6503.
